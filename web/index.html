Roda o seu programa no contrato com entradas aleatórias, sem transação e sem gastar gas.
Cola de sintaxe 
; comentário até o fim da linha
; entrada: r1 aponta para os bytes do input (somente leitura)
; saída: o valor em r0 quando o programa chega em exit
ldxdw r2, [r1+8]      ; lê u64 (também ldxw, ldxh, ldxb)
stxdw [r10-8], r2     ; pilha: 4 KiB abaixo de r10
mov64 r0, 0           ; add64 sub64 mul64 div64 mod64 or64 and64 xor64
lsh64 r2, 1           ; rsh64 arsh64 neg64; versões 32 bits: add32 etc.
lddw r3, 0x123456789abcdef0
jeq r2, 0, fim        ; jne jgt jge jlt jle jset jsgt jsge jslt jsle
ja loop
fim:
exit

1 CU por instrução executada. Limite: 5.000 CU por entrada e 256 instruções. Sem syscalls e sem call.

Jogar esta rodada

  1. Conectar a carteira na BSC testnet

    Precisa de um pouco de tBNB para o gas. Pegar tBNB no faucet.

  2. Enviar o programa lacrado (commit)

    Vai só um hash. Ninguém vê o seu código antes do fim da janela.

  3. Revelar quando o commit fechar

    O contrato roda o programa em 4 entradas sorteadas pelo hash do bloco e conta os CU.

  4. Fechar a rodada

    Qualquer pessoa pode fechar depois do reveal. O menor CU leva a recompensa e abre a próxima rodada.
